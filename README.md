# 引力跳板 · 星际弹弓轨道规划游戏

一款以**引力弹弓（重力助推）**为核心机制的原创轨道规划游戏。玩家为深空探测器编排动作序列——点火变轨、耐心等待、在木星/土星等行星影响球内完成收紧的双曲飞掠——用最省的燃料把探测器送到火星、外太阳系，最终挣脱太阳引力飞出太阳系。

## 玩法

- **5 个关卡**由易到难：火星飞掠 → 小行星带穿越 → 木星引力捕获 → 土星远航（双弹弓接力）→ 星际逃逸
- 三种动作按顺序编排：
  - **等待**：让后续动作推迟 N 天执行
  - **点火**：指定方向（角度）与 ΔV 消耗燃料
  - **弹弓**：选择目标行星与近心点 b（正负决定绕行方向），探测器进入行星影响球时自动结算
- **物理引擎**：简化 N 体模型（太阳引力 RK4 积分 + 双曲飞掠公式），行星沿真实太阳系轨道参数做圆轨道运动
- **评分**：三星 ≤ 55% 燃料预算、二星 ≤ 80%、通关得星；最佳成绩存档（SQLite）
- **成绩记录**：每次发射落库为可追溯的执行档案（动作方案 + 轨迹 + 结算），成绩关联档案可回放、可载入方案继续调优；提交带幂等键，双击/重试/多标签页不会重复记分；兼容旧版存档
- **社区航线挑战**：设计者发布带燃料预算与里程碑的**版本化关卡**（每次发布生成不可变版本，旧版本仍可回放）；玩家提交**幂等结算**的飞行记录（服务端评分 + 幂等键去重）；成绩经**审核**后联动排行榜（按版本结算、每人取最佳）、轨迹回放与关卡解锁（内置关卡/前置挑战/累计星数三种解锁条件）
- **交互**：实时轨迹预览、滚轮缩放/拖动平移、回放动画、策略提示

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（自动挑选空闲端口并打开浏览器）
npm run dev
```

启动后访问控制台输出的地址（如 `http://127.0.0.1:8072`），或直接按 `npm run dev` 自动打开的页面。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 添加动作 | 右侧面板「+ 等待 / + 点火 / + 弹弓」 |
| 调整参数 | 点击动作展开滑杆（角度/ΔV/天数/近心点） |
| 调整顺序 | 动作行 ↑ / ↓ |
| 查看预测轨迹 | 改动自动触发，画布实时显示 |
| 执行任务 | 右上角「🚀 发射」 |
| 轨迹回放 | 画布左上角 ▶ / ⏸，滚轮缩放、拖动平移 |
| 最佳回放 | 顶部「🏆 最佳回放」（已有关卡成绩时出现），可「载入方案」还原动作序列 |
| 社区挑战 | 选关页顶部「🌐 社区航线挑战」：发布/游玩/审核社区关卡 |

## 社区航线挑战

- **设计者**：「发布挑战」填写预算、时限、里程碑（近距飞掠/半径/捕获/弹弓后半径/逃逸）与解锁条件；每次修改通过「＋ 发布新版本」生成不可变版本，成绩按版本结算排行榜
- **玩家**：进入挑战编排动作并发射，飞行记录由服务端结算后幂等提交（双击/重试不重复），进入审核队列
- **审核**：「🗂 审核队列」通过或驳回（本地单机，审核入口开放）；通过后成绩进入排行榜、开放轨迹回放，并按解锁条件联动开放后续挑战

## 关卡目标

| 关 | 名称 | 目标 | 燃料预算(km/s) |
| --- | --- | --- | --- |
| 1 | 火星飞掠 | 近距离飞掠火星 (< 0.18 AU) | 6.9 |
| 2 | 小行星带穿越 | 越过 4.2 AU | 15.6 |
| 3 | 木星引力捕获 | 木星弹弓后被捕获 | 17.3 |
| 4 | 土星远航 | 土星弹弓后远日点 ≥ 15 AU | 16.4 |
| 5 | 星际逃逸 | 挣脱太阳引力（飞出 40 AU 边界） | 19.9 |

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 天体参数、关卡信息、最佳成绩（含可回放记录 id） |
| POST | `/api/preview` | 实时预览轨迹（不评分） |
| POST | `/api/run` | 执行任务并评分（星级），执行档案落库并返回 `run_id` |
| POST | `/api/score` | 提交成绩：`run_id` 关联执行档案 + `submission_id` 幂等键；兼容旧版仅带 `stars` 的提交 |
| GET | `/api/scores/{level_id}/records` | 某关成绩提交记录（追溯列表） |
| GET | `/api/records/{record_id}` | 成绩记录详情：动作方案 + 轨迹（供回放） |
| GET | `/api/challenges` | 社区挑战列表：当前版本摘要 + 解锁状态 + 本机最佳（已审核）+ 待审数 |
| POST | `/api/challenges` | 发布新挑战（预算 + 里程碑 + 解锁条件），生成不可变 v1 版本 |
| GET | `/api/challenges/{cid}` | 挑战详情：版本列表 + 当前版本完整定义 + 解锁状态 |
| POST | `/api/challenges/{cid}/versions` | 发布新版本（不可变，旧版本保留；可同步调整解锁条件） |
| GET | `/api/challenges/{cid}/versions/{v}` | 指定版本完整定义 |
| POST | `/api/challenges/{cid}/preview` | 挑战轨迹预览（不评分、不落库） |
| POST | `/api/challenges/{cid}/run` | 挑战飞行结算：执行档案落库返回 `run_id`（未解锁 403） |
| POST | `/api/challenges/{cid}/submit` | 提交飞行记录：`run_id` + `submission_id` 幂等键 → 待审核 |
| GET | `/api/challenges/{cid}/leaderboard` | 排行榜：仅审核通过，按版本结算，每人取最佳（`?version=` 可查旧版） |
| GET | `/api/challenges/review_queue` | 全站待审核成绩队列 |
| POST | `/api/challenges/submissions/{id}/review` | 审核成绩（approve/reject）：通过后上榜、开放回放并联动解锁 |
| GET | `/api/challenges/submissions/{id}` | 成绩详情：审核通过后附带动作方案与轨迹（供回放） |

## 物理模型说明

- 距离 AU、时间 天、速度 AU/天（1 AU/天 ≈ 1731.5 km/s）
- 弹弓结算：入轨相对速度 v_inf、近心点 r_p 下，偏转角 δ = 2·asin(1/(1 + r_p·v_inf²/μ))，相对速度大小守恒（能量守恒）
- 行星间互不摄动；探测器在弹弓事件之间只受太阳引力（RK4）
- 近心点小于行星半径会解体；燃料耗尽或超时判负
